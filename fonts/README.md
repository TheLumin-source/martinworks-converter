# Bundled fonts

The app loads these privately at runtime (they are never installed system wide)
to match the martinworks.org look: Cinzel for headings, Crimson Pro for body
text. If loading fails the app falls back to Georgia or Constantia, so the
fonts are a nicety, not a requirement.

Both families are licensed under the SIL Open Font License, Version 1.1, which
permits bundling and redistribution with software. The full licence text is in
`OFL.txt`.

- Cinzel, by Natanael Gama. Reserved Font Name "Cinzel".
- Crimson Pro, by Jacques Le Bailly, based on Crimson Text by Sebastian Kosch.
  Reserved Font Name "Crimson".

Modified versions of either family must not use the Reserved Font Names.
